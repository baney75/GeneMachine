        If you have tested with a consumer DNA service, you can usually download a raw data file from your account. Download steps change, so follow the provider's own instructions. They may ask you to confirm your identity first.

        Unzip it on this device

        1. Save the download to a private folder on your own computer, not a shared or public one.
        2. Unzip it locally. On a Mac, double-click the .zip file in Finder. On Windows, right-click it and choose Extract All.
        3. Choose the extracted .txt or .csv file in the DNA check above. GeneMachine cannot open .zip or .gz archives.
        4. Do not upload the file to online converters or other websites to fix its format. If GeneMachine cannot read it, it says why.

        No file yet? What to know before choosing a test

        A

        Ancestry kits are not medication tests

        Consumer ancestry kits use a genotyping array that reads a preselected set of positions. They do not read every gene and can miss positions that matter for a medicine.

        B

        Check the terms before you buy

        Look at whether the service offers a raw data download, how it stores and deletes your data, and what it says about medical use. Some providers state that raw data is not for medical decisions.

        C

        For a medication decision, ask about clinical testing

        If a prescriber needs genetic information to choose or dose a medicine, ask them or a pharmacist about a clinical pharmacogenetic test from an accredited laboratory (in the U.S., CLIA-certified).

        GeneMachine does not sell tests or endorse any provider. The FDA explains what direct-to-consumer tests (opens in a new tab) can and cannot tell you.

        04PRIVACY, PLAINLY

        What happens to your file.

        GeneMachine has no account, no upload, no analytics, and no browser storage. Here is what that covers, and what it does not.

        01While reading
        The file is read into this browser tab's memory and parsed there. It is not uploaded.
        02After parsing
        The analysis worker is terminated, releasing the raw text and full genotype table. The derived result, including counts, the file fingerprint, and the one marker if found, stays in the tab while it is on screen.
        03Clear this DNA now
        Removes the derived result from the page. It does not delete your original file from your device or any report you downloaded. Closing the tab also discards it.
        04Downloads
        The discussion report and question list are HTML files saved to your device. The report leaves out the original filename and raw rows but includes the derived observation. Store, share, or delete it like any health document.
        05Outside GeneMachine
        Browser extensions, shared accounts, device backups, and synced download folders can expose files. Use a private device you trust.

        05PLAIN-LANGUAGE GLOSSARY

        Words you will see.

        Short, beginner-level definitions. Open any term to read it.

        Genotype

        The pair of DNA letters you have at one position, one copy inherited from each parent. For example, T/C means one copy reads T and the other reads C.

        Genome build

        The version of the human reference map used to number DNA positions, such as GRCh37 or GRCh38. The same marker has a different position number in each build, so a file has to say which one it uses.

        Marker

        A specific, named position in the genome that a test reads, often labeled with an ID such as rs4149056. Consumer DNA tests read hundreds of thousands of markers, which is still a small fraction of the genome.

        No-call

        A position the test tried to read but could not determine with confidence, often written as -- or 00. A no-call is unknown. It is not the same as a normal result.

        Pharmacogenetics

        The study of how inherited DNA differences can affect how your body processes or responds to certain medicines. Confirmed results can inform a clinician's choice. They do not replace it.

        Phenotype

        An observable trait. In pharmacogenetics it usually means a predicted function label, such as decreased function of a transporter or enzyme. Assigning one usually needs several markers and clinical-grade testing. GeneMachine does not assign phenotypes.

        Strand (orientation)

        DNA has two matching strands. A file has to say which strand its letters come from, usually forward or plus. Without that, the same position can be misread as different letters.
