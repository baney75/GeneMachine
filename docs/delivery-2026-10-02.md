# GeneMachine educational candidate: October 2, 2026

Baseline: `290741c` on `sol/genemachine-pgx`. Candidate branch: `codex/genemachine-pro-20261002`.

## Delivered behavior

The no-DNA library exposes seven sourced medicine topics, gene/medicine/brand search, specific unknowns, and up to five appointment questions. A local HTML checklist carries the selected topics, uncertainty, guideline links, and review date. It does not inspect DNA or advise treatment.

The redesigned DNA journey preserves one gated SLCO1B1 rs4149056 observation and abstention for unsupported inputs. Parsing/hashing run in a worker. Only aggregate QC, the finding, capability map, and original-byte hash return to the UI. The worker is terminated after completion or cancellation. Withdrawing consent cancels work and clears the derived DNA result; original files and downloaded copies remain on device.
